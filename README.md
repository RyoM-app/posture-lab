# 姿勢ラボ（実験用プロトタイプ）

作成日：2026-10-16。対象：iPhone 15 Pro / iOS 26.2 / Safari、Pixel 9a / Android 15 / Chrome。

**実機動作・精度・回転軸の対応は未確認。既存の iris-distance-demo は変更していない。**
現在は共通の計測部分を実装。仮CVAのモデルはユーザーと確認中で、数値を表示しない。

## 開く方法

このディレクトリを静的WebサイトとしてHTTPS配信し、スマートフォンのSafari / Chromeで直接開く。スマートフォンからPCの `http://192.168.x.x` に接続するだけではセンサーを利用できない。LINE等のアプリ内ブラウザは対象外。

PCでの表示には、このディレクトリで `python3 -m http.server 8000` を実行し、PC自身の `http://localhost:8000` を開く。スマートフォン向け公開先は未設定。

追加のビルド工程はない。配信対象は index.html、styles.css、app.js、geometry.js、vision-worker.js。研究資料や計測データは配信ディレクトリに置かない。

## 操作

1. 縦持ち・着座で「カメラ・IMUを開始」を押し、カメラと動作・方向を許可する。
2. 顔・虹彩・IMUが受信できているか表示を確認する。
3. 安定した姿勢で「この姿勢を基準にする」を押し、3秒間静止する。
4. 任意：レンズから目までの距離を測り、中央付近に目を置いて距離校正する。
5. 記録開始 → 動作 → 記録停止 → CSVと全記録JSONを保存する。

カメラ画像は送信・保存しない。開始時にjsDelivrとGoogleのストレージからライブラリ・モデルを取得するため通信が必要。完全オフライン版ではない。
数値は最大20分間記録。約5秒ごとにIndexedDBへ途中退避する。モバイルOSによる終了直前の書き込みは保証しない。終了時に必ずダウンロードを確認する。自動退避できない場合は画面に表示する。

## 計算方法と限界

### 虹彩径と距離

- 478点のうち左右の虹彩外周を使用。各目の2本の直径の大きい方を取り、その左右平均を p とする。楕円の真の長軸を厳密に求める方法ではない。
- 未校正：仮の水平画角60度、虹彩径11.7 mmから `Z[cm] = f[px] × D[mm] / p[px] / 10`。両仮定は設定変更可能。機種固有の焦点距離・画角を取得した値ではない。
- 1点校正：`K = 実測距離[cm] × 校正時の虹彩径[px]` を保持し、`Z = K/p`。焦点距離と虹彩実寸を個別に同定する方法ではない。
- 基準からの距離比：`p_baseline/p × 100%`。未校正でも表示する。
- Zは光軸方向の奥行き。中心付近で校正して直線距離との違いを小さくするが、主点・歪み・虹彩個人差・視線・オートフォーカス・クロップの影響を解決したわけではない。
- 手持ちでは端末と頭の並進を分離できない。距離変化をCVA変化や頭部前方変位と同一視しない。

### 頭部回転とIMU

MediaPipeの顔変換行列から回転軸を抽出。元デモと同じ行列格納順の推定を使用し、格納順フラグと元行列をJSONに保存する。
DeviceOrientationの `Rz(alpha) Rx(beta) Ry(gamma)` から、端末座標で表した鉛直上向きベクトルを求める：

`u = (-cos(beta)sin(gamma), sin(beta), cos(beta)cos(gamma))`

未反転の前面カメラの顔正面ベクトルを n として、端末座標へ `n_device = (-n_x, n_y, -n_z)` と変換し、下向きを正とする傾き `h = -asin(dot(n_device, u))` を算出。表示値は `h - h_baseline`。縦持ちのみ。鏡像処理はCSS表示に限定する。

これは顔の正面軸の鉛直に対する傾きであり、C7–耳珠ベクトルの角度ではない。実端末で方向・符号・端末を回したときの相殺を確認する必要がある。未受信のIMUを0度として補完しない。

仮CVAは計算モデルの合意待ち。基準姿勢取得だけで実測CVAは分からない。

### 時刻と品質

画像を処理に渡す直前のperformance.nowを時刻とし、その時点で最新の方向イベントを対応付ける。補間・厳密な同期は未実装。画像のハードウェア露光時刻ではない。IMUのイベント時刻と受信時刻、動画のcurrentTime、推論時間、結果受信時刻を別々に保存する。
方向情報が250 msより古い場合は頭部の重力補正を表示しない。顔未検出や設定範囲外の回転、虹彩径不足、目の開き不足、左右径の大きな不一致を除外する。これらは暫定しきい値で、精度を保証しない。

顔推定は原則Workerで実行。非対応時はメインスレッドへ切り替え、推定頻度を抑える。主処理が遅い場合に古い画像を蓄積しない。画面非表示時は記録を停止し、自動再開しない。縦横変更時は基準を無効化する。

## ファイル
